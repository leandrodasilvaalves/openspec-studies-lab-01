### Módulo 1: Setup e Inicialização ⚙️

Antes de criarmos o código C#, precisamos garantir que o projeto base existe e que o **OpenSpec** está inicializado na raiz do repositório para que o **OpenCode** encontre as especificações com clareza.

1. **Crie a pasta do laboratório e a solução .NET:**
* 🗂️ Crie um diretório de trabalho e inicialize uma solução/projeto console em C# (ex.: `FakeDataCli`).


2. **Adicione o pacote `Bogus`:**
* 📦 Instale a biblioteca `Bogus` no projeto console para termos suporte a `pt_BR` e geração de dados.


3. **Inicialize o OpenSpec e abra o OpenCode na raiz do projeto:**
* 📄 Execute o comando de inicialização do OpenSpec na raiz do repositório para gerar a estrutura de diretórios/arquivos de especificação do projeto.
* 💻 Abra o **OpenCode** dentro dessa mesma pasta raiz para que ele tenha contexto do repositório.
